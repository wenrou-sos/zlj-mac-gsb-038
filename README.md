# 城市垃圾分类成效分析看板

Python / Streamlit + Plotly,数据为模拟 CSV。

## 运行

```bash
pip install -r requirements.txt
python generate_data.py        # 重新生成模拟数据(可选,仓库已含生成结果)
streamlit run app.py           # 打开 http://localhost:8501
```

## 数据(data/)

| 文件 | 内容 |
|---|---|
| `communities.csv` | 26 个小区:所属街道、总户数、定时定点投放站点数 |
| `daily_records.csv` | 6812 行每日记录(2026-01-01 ~ 09-19):厨余/可回收/有害/其他四类分出量、分对量(`correct_kg`)、混投量(`mixed_kg`)、当日参与户数 |
| `contamination.csv` | 小区 × 月的混投成分(6 类,如"厨余袋混入塑料瓶/塑料袋") |

关键口径:**分类准确率 = correct_kg ÷ total_kg**;**参与率 = 当日参与户数 ÷ 总户数**。

## 看板功能

- **KPI 总览**:垃圾总量、分类准确率、居民参与率、混投量、厨余占比
- **街道排名**:各街道分类准确率横向柱状图(红绿渐变 + 预警线)
- **混投预警**:准确率低于阈值(侧栏可调,默认 80%)或连续 3 个月下滑的小区,整行标红
- **月度趋势**:整体 / 按街道 / 按小区三种维度,预警小区加粗显示
- **每日四类分出量**:堆叠柱状图
- **参与率**:各小区横向排名 + 全市平均线
- **混投成分分析**:预警小区混投类型堆叠条形图 + 全市混投构成环形图
- **明细数据**:小区 × 月准确率热力表(红黄绿渐变)、每日记录抽样、混投明细

侧栏支持按统计周期、街道、小区筛选,所有图表联动。
