# 城市垃圾分类成效分析看板

基于 Python / Streamlit + Plotly 的城市垃圾分类成效分析看板，数据为模拟生成的 CSV。

## 功能

- **KPI 总览**：累计分出量、总体分类准确率（正确投放 vs 混投）、定时定点投放参与率、混投事件数
- **街道排名**：各街道分类准确率排名柱状图（红黄绿色阶 + 全市平均线）、四类垃圾分出量堆叠图
- **月度趋势**：各街道分类准确率逐月走势，自动标注上升 / 下降街道
- **居民参与率**：定时定点投放站点参与率排名（日均投递户数 / 总户数）及月度趋势
- **混投分析**：混投率超阈值小区自动标红（阈值可调）、混投率 TOP10、
  混投品类构成（厨余袋混塑料瓶 / 纸巾、有害垃圾混入其他垃圾等）饼图与占比对比
- 侧边栏支持日期范围、街道筛选，筛选后明细可下载 CSV

## 运行

```bash
pip install -r requirements.txt
python generate_data.py        # 生成 data/*.csv 模拟数据
streamlit run app.py           # 启动看板
```

## 数据说明

| 文件 | 内容 |
|---|---|
| `data/daily_classification.csv` | 各社区每日四类垃圾分出量（kg）、正确/混投投放次数、总户数、参与户数 |
| `data/misthrow_detail.csv` | 各社区每日混投明细（6 类混投类型 × 次数） |

指标口径：

- **分类准确率** = 正确投放次数 /（正确投放次数 + 混投次数）
- **参与率** = 当日投递户数 / 小区总户数
- **混投率** = 1 − 分类准确率，默认 ≥ 12% 标红（侧边栏可调）
